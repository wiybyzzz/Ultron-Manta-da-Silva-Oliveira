# 🤖 ULTRON — Agente de Respostas com IA

Chat web do **ULTRON** com IA local + integração opcional ao **Google Gemini (grátis)** que entende texto, fotos, vídeos e áudios.

## ✨ Funções
- 💬 Conversa com IA (modo local + Gemini grátis)
- 📷 Envio de fotos (com análise pela IA avançada)
- 🎬 Envio de vídeos (com análise pela IA avançada)
- 🎙 Mensagens de voz (transcrição + resposta, inclusive por voz)
- 🔊 Voz natural em português (sem ler emojis, não trava em textos longos)
- 🗑 Apagar conversa
- 🌙 Interface escura

## 🚀 Como executar (Windows)
1. Clique duplo em `ABRIR-ULTRON.bat`
2. O navegador abre em `http://localhost:8080`

Sem servidor (limitado): abra `index.html` direto (microfone e IA avançada exigem o servidor).

## 🧠 Ativar a IA avançada (Gemini, grátis)
1. Acesse `aistudio.google.com` e crie uma API key gratuita
2. No Ultron, abra as Configurações e cole a chave
3. Pronto: ele passa a responder e enxergar fotos, vídeos e áudios de verdade

## 🛠 Requisitos
- Node.js (https://nodejs.org)
- Navegador Chrome ou Edge (recomendado)
